About This Project

Project Overview

AI-Based Intrusion Detection System for Cloud Networks is a mini project developed as part of the curriculum on "AI for Improving Security for Cloud Networks" at Matrusri Engineering College. This system demonstrates how machine learning can be applied to network security problems, specifically identifying malicious network traffic patterns.

The project combines data science, cloud security concepts, and web application development to create a practical tool that securely analyzes network connections and detects intrusion attempts using a trained Random Forest model on the NSL-KDD benchmark dataset.
